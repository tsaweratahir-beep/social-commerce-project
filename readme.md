# 🛍️ SmartCommerce - AI Recommendation System

##  Project Overview
SmartCommerce is a **complete e-commerce recommendation system** like Alibaba.com and Daraz. It uses AI to recommend products based on user preferences, trending items, and popular products.

---

##  Features

### Core Features
-  **AI-Powered Recommendations** - Similar products suggestion
-  **Trending Products** - Based on ratings + sales
-  **Popular Products** - Most sold items
-  **Smart Search** - Search by name or category
-  **Category Filter** - 10+ product categories
-  **Dynamic Pricing** - Discounts and offers
-  **Rating System** - Customer reviews (1-5 stars)
-  **Responsive Design** - Mobile friendly

### Technical Features
-  RESTful API
-  Real-time data fetching
-  No database required (CSV based)
-  Easy to deploy
-  Lightweight & fast
